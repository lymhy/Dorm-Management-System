## 二、一键启动（推荐）

打开 PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File D:\my-projects\dorm\start-all.ps1
```

脚本会自动完成四件事：
1. 检查并启动 MySQL80 服务（已启动则跳过）
2. 新开一个窗口运行后端（`start-backend.ps1`）
3. 轮询等待后端监听 8080（最多 90 秒，输出 `Backend is listening on 8080.`）
4. 新开一个窗口运行前端（`start-frontend.ps1`）

第 3 步是必需的：Vite 秒级就绪并自动打开浏览器，若后端尚未监听，浏览器中仍然有效的
登录态会直接进入系统并并发请求，导致 Vite 代理 `ECONNREFUSED`、页面提示「无法连接后端服务」。

**主窗口出现 `Backend is listening on 8080.`、后端窗口出现 `Started DormApplication in x.x seconds` 即启动完成**（约 20~40 秒）。
然后浏览器自动打开：**http://localhost:5173**（被占用时自动顺延，以窗口 `Local:` 为准）

停止服务：

```powershell
powershell -ExecutionPolicy Bypass -File D:\my-projects\dorm\stop-all.ps1
```

## 三、分步启动（排错时用）

### 1. 启动 MySQL

```powershell
net start MySQL80          # 启动
net stop  MySQL80          # 停止
Get-Service MySQL80        # 查看状态
```

### 2. 启动后端

```powershell
powershell -ExecutionPolicy Bypass -File D:\my-projects\dorm\start-backend.ps1
```

`start-backend.ps1` 内部做的事（等价手工命令）：

```powershell
$env:JAVA_HOME = "D:\tools\jdk21\jdk-21.0.7+6"
$env:PATH = "$env:JAVA_HOME\bin;" + $env:PATH
cd D:\my-projects\dorm\backend
D:\tools\maven\apache-maven-3.9.9\bin\mvn.cmd spring-boot:run
```

启动成功的标志：
```
Tomcat started on port 8080 (http)
Started DormApplication in 12.345 seconds
```

### 3. 启动前端

```powershell
powershell -ExecutionPolicy Bypass -File D:\my-projects\dorm\start-frontend.ps1
```
等价手工命令：
```powershell
cd D:\my-projects\dorm\frontend
npm run dev
```
成功标志：
```
VITE v5.4.21  ready in xxx ms
➜  Local:   http://localhost:5173/
```

## 六、常见问题

**Q1：登录按钮点了没反应**
按 `F12` 看 Console。若出现 `xxx is not a function`，说明 `frontend/src/api/` 下某个 api 模块被改坏了（例如 `api/user.js` 丢了 `login` 方法）。
注意：任何 api 模块都可能有页面在 `import`，改前先全局搜索谁在用。

**Q2：`ERROR: port 8080 is already in use`**
上一次的后端没退干净。执行：
```powershell
powershell -ExecutionPolicy Bypass -File D:\my-projects\dorm\stop-all.ps1
```
`stop-all.ps1` 会等到端口真正释放并逐个确认，并一并清理前端可能占用的 5173-5179。
> 前端不必担心端口冲突：5173 被占用时 Vite 会自动顺延（5174、5175…）并自动打开浏览器到实际地址。

**Q3：提示 `Access denied for user 'root'`**
`application.yml` 里的数据库密码与你本机不一致，改成 `1234`（或你自己的密码）。

**Q4：前端报 404 / 接口全红 / 登录后立刻被踢**
大概率是**后端没起来**。先确认 8080 端口在监听，再看后端窗口有没有报错。

**Q5：PowerShell 里中文是乱码**
只是终端显示问题（GBK/UTF-8 之故），不影响功能。要正常显示先执行：
```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

**Q6：`mvn` 报 `JAVA_HOME` 或版本错误**
必须用 JDK 21。`start-backend.ps1` 已强制指定，手敲命令时记得先手动设置 `JAVA_HOME`。

**Q7：数据库里没有数据 / 表不存在**
执行建表脚本（`database` 目录）：
```powershell
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p1234 dorm --default-character-set=utf8mb4 -e "source D:/my-projects/dorm/database/init.sql"
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p1234 dorm --default-character-set=utf8mb4 -e "source D:/my-projects/dorm/database/notification.sql"
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p1234 dorm --default-character-set=utf8mb4 -e "source D:/my-projects/dorm/database/fee_payment.sql"
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p1234 dorm --default-character-set=utf8mb4 -e "source D:/my-projects/dorm/database/payment.sql"
```

> 四个脚本按 `init.sql → notification.sql → fee_payment.sql → payment.sql` 顺序执行；库内应有 15 张表。

**Q8：在线缴费（模拟支付）怎么演示？**
1. 用管理员登录 → 「水电费」生成一条未缴账单（房间需有在住员工）
2. 用该房间的员工账号（如 `zhangwei`）登录 → 「在线缴费」→ 未缴账单点「在线支付」
3. 收银台弹窗点「确认支付」→ 账单自动核销、生成缴费流水、员工收到「缴费成功」通知
4. 管理员在「缴费流水」看到 `在线支付` 记录，在「费用报表」看到金额变化
> 当前只有 `mock` 模拟通道，`wechat` / `alipay` 为预留扩展点（实现 `PaymentGateway` 接口即可）。
